# AntiDroid

An unofficial, standalone Android APK wrapper for the [Google Antigravity](https://antigravity.google.com) remote control web PWA.

> **Disclaimer:** AntiDroid is an unofficial wrapper that is not affiliated with, endorsed by, or sponsored by Google.

## Features

- **Full Screen and Standalone:** Displays Antigravitys PWA edge to edge with status bar and navigation bar matching the sites background.
- **In App Google Sign In:** Supports persistent cookies and OAuth popups so the google sign in works natively inside the app.
- **Outside Link Support:** Opens remote control handoff links directly in AntiDroid while routing external links to your default browser.
- **Web Capabilities:** File uploads and downloads, microphone, hardware back navigation, keyboard handling, and an offline retry overlay.

## Prerequisites for self compiling.
- JDK 17
- Android SDK (API 34 + Build Tools 34.0.0)
- Gradle 8.7+
